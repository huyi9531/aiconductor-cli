# 抖音爆款选题

## 概述

此 Skill 通过全局安装的 `aiconductor-cli` 命令行工具检索抖音视频，把搜索结果清洗成"哪些内容在爆、为什么爆、你该怎么拍"。

适用环境默认已配置好 CLI 和 API Key。当遇到 `command not found`、缺少密钥、鉴权失败或版本不兼容时，读取 [references/aiconductor-skills-setup.md](references/aiconductor-skills-setup.md)，修好后重试原命令一次；再失败就把原始错误交给用户。仅当用户明确要求初始化或配置 Skill 时才主动读取该文件。

## 什么时候用

- 想开拍，但不确定拍什么、这个方向还值不值得做
- 找对标视频，看同行最近在发什么、什么形态奏效
- 判断一个选题词在抖音是"真赛道"还是"自嗨词"

不接这几种，直说原因：

| 不接的请求 | 原因 |
|---|---|
| 单条视频为什么爆 | 那是逐条拆解，本技能只做批量发现 |
| 评论区怎么说 | 评论是另一条链路，本技能不读评论 |
| 把爆款文案扒下来 | 转写是另一件事 |
| 某个账号整体怎么样 | 账号维度分析不在本技能范围 |
| 下载视频 | 不提供 |

## 执行

### 1. 定档

用户没说时间窗就用默认档，不要反问"你要哪个时间段"。

| 档位 | 参数 | 什么时候用 |
|---|---|---|
| 近一周最热（默认） | `--sort-type 1 --publish-time 7 --max-pages 1` | 看当下什么在跑 |
| 半年爆款池 | `--sort-type 1 --publish-time 180 --max-pages 2` | 找可复刻的长期赢家 |
| 最新动向 | `--sort-type 2 --publish-time 1 --max-pages 1` | 追热点、看刚起量的 |
| 长视频对标 | `--sort-type 1 --filter-duration 5-10000` | 口播、知识、测评类 |

### 2. 跑一次

```bash
aiconductor-cli douyin video-search "AI编程" --sort-type 1 --publish-time 7 --max-pages 1 \
  | node scripts/clean.mjs -
```

单次约 5–10 秒。一页通常只回 7 条左右，`has_more` 经常还是 1——这不是失败，是抖音返回的就是小分页。

### 3. 关键词怎么给

第一轮用用户原话。第二轮不要凭空想同义词，**从第一轮结果 `desc` 里的 `#话题` 挑 2–3 个高频标签**再搜——话题标签比近义词更接近抖音自己的分类，也更容易暴露出"这个词被哪类内容占了"。

合并多轮结果时按 `aweme_id` 去重。最多 4 个词、串行跑，开跑前说一句"要搜 N 轮"。

### 4. 清洗

`scripts/clean.mjs` 已经处理机械部分，这几个单位坑不用你再想：

- **时长**：`video.duration` 的单位是**毫秒**，当秒用会差三个数量级
- **时间**：`create_time` 是「北京时间编码成的 epoch」——按 UTC 渲染出来就是北京时间，**不要再 +8 小时**。实测 2026-10-28：加 8 小时会把半小时前发布的视频放到 7 小时后。脚本按这个口径渲染，一旦发现时间跑到未来会打印告警
- **去重**：按摘要前 24 字合并同一条内容的多账号搬运
- **过滤**：丢弃 <10 秒的切片/图文
- **排序**：按点赞降序，并算出赞粉比

剩下三件脚本做不了、只能靠判断：

1. **相关性**：因为作者昵称或账号定位含关键词才被搜进来的内容要删掉。实测搜"程序员"，第一名是"程序员博博"发的《黑龙江凌晨3点天就亮了》——纯地理内容，与赛道无关。
2. **真假爆款**：看赞粉比。>1 说明这条远超账号体量，是内容本身跑赢了；粉丝 100 万只有 3000 赞，那是存量不是爆款。低于 0.01 的基本可以当噪声。
3. **样本量**：清洗后不足 3 条，说明这个词在抖音不是有效赛道，别硬凑结论。直接说"这个词样本不足"，给 2–3 个更口语的替代词（"AI编程" → "AI写代码""程序员副业"），让用户选。

### 5. 交付

固定四段，不要自由发挥：

1. **榜单** 5–8 条：北京时间 | 点赞 | 评论 | 时长 | 作者(粉丝) | 赞粉比 | 标题
2. **共性**：时长区间、发布时段、标题/开头钩子、内容形式（口播/实拍/图文）。只写榜单里**实际出现过**的，别套模板
3. **选题建议** 3 条：每条一句话，挂 1–2 条支撑作品（标题或 aweme_id），说清"照这个拍是踩着什么规律"
4. **口径**：点赞是抓取时点的快照；`has_more=1` 就明说"只看了第一页，不是全量"

## 失败怎么说

| 现象 | 多半是 | 怎么讲 |
|---|---|---|
| `data.data.success === false` | 鉴权、账号状态或上游异常 | 看 `message` 原话，按 references 处理 |
| `video_list` 为空 | 关键词太窄或时间窗太短 | 这个词近 N 天没搜到内容，换更口语的说法或放宽到半年 |
| 清洗后只剩 1–2 条 | 词不是赛道词 | 直说样本不足，给替代词 |
| `has_more=1` | 只取了一页 | 结论里标注"非全量"，不要说成"全部爆款" |

不要因为结果少就改写结论、也不要拿单条视频代表赛道。

## 限制

- 单次请求 `max_seconds` 上限 50 秒，翻页会被截断，但 `success` 仍为 `true`——判断是否取全看 `has_more`
- 搜索是关键词匹配，不是赛道理解，噪声是常态
- `play_count` 常常是 0，别拿播放量当指标，用点赞/评论/收藏
- 不下载视频、不读评论、不提取文案
